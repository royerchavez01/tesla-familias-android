# Tesla Familias

Aplicación Android para consultar asistencias, obligaciones y avisos de un estudiante. Entrega final del módulo 8, versión 1.0.0.

- [Documentación, instalación y resultados](README_Tesla_Familias.md)
- [APK instalable](entrega/TeslaFamilias-1.0.0.apk)
- [Capturas de la aplicación](capturas)

**Acceso de demostración:** usuario `demo`, contraseña `tesla123`, o botón de entrada directa.

El proyecto funciona con datos ficticios guardados en el teléfono y no necesita conexión a SIGAF.

[Portafolio, informe, presentación y QR](PORTAFOLIO.md)
