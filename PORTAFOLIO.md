# Portafolio de Tesla Familias

**Royer Alexander Chavez Malaver**

Desarrollo de Aplicaciones Móviles · Entrega final del módulo 8

Tesla Familias permite consultar asistencias, obligaciones y avisos de un estudiante. La versión 1.0.0 funciona con datos ficticios guardados en el teléfono y cuenta con un administrador de demostración.

El QR contiene la dirección directa del APK alojado en este repositorio. Para instalar, se requiere Android 8.0 o superior. El acceso de prueba es `demo` / `tesla123`; también se puede entrar con el botón de demostración.

## Reflexión

El proyecto reúne varias tareas que deben mantenerse relacionadas: mostrar los datos, permitir cambios y conservarlos después de cerrar la aplicación. Separar el guardado de las pantallas ayudó a revisar que la asistencia y las obligaciones mostraran los mismos valores en cada consulta. La prueba de notificaciones también permitió distinguir entre el aviso del sistema y el historial guardado. La siguiente etapa sería conectar SIGAF y revisar el uso con familias reales. Antes de hacerlo, falta desarrollar autenticación institucional y el tratamiento de los datos de los estudiantes.
